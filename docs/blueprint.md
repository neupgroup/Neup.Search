# **App Name**: NeupSearch

## Core Features:

- Unified Search Bar: Display a universal search bar prominently on the homepage and search results page.
- Tabbed Results: Present search results in distinct tabs: Web, Images, Videos, and Documents.
- Search Filters: Implement filtering options such as date, type, and source.
- AI Q&A: Offer an AI Q&A feature using an LLM tool to generate answers to user questions, summarizing information from top search results and citing sources. Start with the OpenAI API for the LLM.
- Theme Toggle: Toggle between light and dark themes for user preference.
- Image Upload: Enable image search by allowing users to upload or drag and drop images.

## Style Guidelines:

- Primary color: A deep, saturated blue (#3F51B5) evoking trust and intelligence, reflecting the app's core search functionality. A somewhat brighter blue than #3F51B5 may be called for in order to make a light scheme accessible.
- Background color: A light gray (#ECEFF1), almost the same hue as the primary, for a clean and modern interface.
- Accent color: A vibrant orange (#FF9800) used sparingly for highlights and calls to action, creating contrast and guiding the user's eye.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines combined with 'Inter' (sans-serif) for body text to offer a balance of modernity and readability.
- Use a set of consistent, minimalist icons to represent different file types and search filters.
- Employ a clean, grid-based layout to ensure readability and easy navigation, placing the search bar at the top for immediate access.
- Incorporate subtle, tasteful animations for loading indicators and search result transitions to provide feedback without disrupting the user experience.
